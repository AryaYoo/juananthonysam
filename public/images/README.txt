Panduan Logo Ekklesia Surabaya:
====================================
Letakkan file logo gereja Anda di dalam folder ini:
- Format yang didukung: logo.png, logo.svg, atau logo.jpg
- Rekomendasi nama file: logo.png (latar belakang transparan, rasio 1:1 persegi atau lingkaran)
- Rekomendasi ukuran: 256x256 pixel atau 512x512 pixel

Ketika file logo.png diletakkan di sini, website akan otomatis menampilkannya pada navbar dan footer.
